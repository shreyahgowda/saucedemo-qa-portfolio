# SauceDemo (Swag Labs) — Manual QA & Exploratory Testing Portfolio

Manual functional, negative, and exploratory testing suite for the **Swag Labs** e-commerce web application (`https://www.saucedemo.com`).

## Scope & Test Summary
* **Modules Tested:** Authentication, Product Inventory & Sorting, Shopping Cart, Checkout Flow, Session Management
* **Total Test Cases Executed:** 10 (`6 Passed`, `4 Failed`)
* **Defects Logged:** 5 reproducible functional and UI bugs (`2 High`, `3 Medium`)

* [`bug-reports.md`](./bug-reports.md) — Detailed defect reports with severity, steps to reproduce, and expected vs. actual results
